# Task Manager App

A simple web-based To-Do list application built with Node.js, HTML, CSS, and JavaScript. It is containerized with Docker and includes CI/CD using GitHub Actions.

## Features
- Add tasks
- View tasks
- Minimal frontend + backend

## DevOps Integration
- Dockerized application
- GitHub Actions for CI/CD
- Ready to deploy on Render or Railway

## Run Locally

```bash
npm install
node server.js
```

Visit `http://localhost:5000`
